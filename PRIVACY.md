# InternBot Privacy Policy

InternBot is a personal tool used only by its developer, Sidh Mittal (sidhmittal175@gmail.com).

What it accesses: with the user's permission, it reads job-alert emails in the user's own Gmail
account, creates email drafts, and sends a daily summary email to the user's own address.

How data is used: this data is processed only on the user's own computer to find internships and
write draft emails. Email text may be sent to a language model service (a local model or the
Google Gemini API) to write draft wording.

Storage and sharing: data is stored only on the user's own computer. It is not sold, shared with
third parties, or used for advertising. The app is not offered to other users.

Contact: sidhmittal175@gmail.com
